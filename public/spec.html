Format Spec - MAGIC RISA v3

.rissa - deterministic, versioned, streaming.

File := MAGIC(4) VER(1) BACKEND(1) NUM_BLOCKS(4) BLOCK_SIZE(4) DICT_LEN(4) DICT? [DICT]
        { Block }*
Block:= TID(1) EXTRA_LEN(1) ORIG_LEN(4) COMP_LEN(4) EXTRA? COMP
MAGIC = 0x52 49 53 41 "RISA" (rissa)
VER   = 3 (legacy DCM2/DCMP auto-migrated)
BACKEND 0=huffman 1=zlib 2=lzma 3=zstd
TID 0=RAW 1=DELTA 2=XOR_DELTA 3=DELTA2 4=MTF 5=BWT_MTF 6=SHUFFLE_2 7=SHUFFLE_4 8=SHUFFLE_8
    9=DELTA_ZIGZAG 10=DELTA2_ZIGZAG 11=ORDER2 12=BWT_MTF_RLE 13=FLOAT_SPLIT 14=BIT_TRANSPOSE 15=SHUFFLE4_DELTA
EXTRA 0-2B: BWT primary >H, SHUFFLE stride 1B, else 0
COMP  = backend( transform(block) )  e.g. zstd(level)

Streaming

compress_stream(in, out, block_size=131072, use_dict=False) - for block in stream without whole-file RAM. Dict built from first 1MB, MDL-gated (with+dict < without).

Determinism

Sorted TRANSFORMS_V2 iteration, no hash tie-break. Same input → same .rissa.

Python API

import rissa
compressed = rissa.compress(data, level=3) # 1:3 2:6 3:19 4:22
assert rissa.decompress(compressed) == data
# or
from deep_compress.compressor_v3 import compress_with_dict
comp, hist, d = compress_with_dict(data, backend="zstd", block_size=131072, use_dict=True)
