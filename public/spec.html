Format Spec — MAGIC RISA v4.1

.rissa — deterministic, versioned, streaming. Updated from v3 (64K/128K) to v4.1 (1M/4M adaptive)

Overview

File := MAGIC(4) VER(1) BACKEND(1) NUM_BLOCKS(4) BLOCK_SIZE(4) DICT_LEN(4) DICT_ORIG_LEN(4) DICT? [DICT_COMP]
        { Block }*
Block:= TID(1) EXTRA_LEN(1) ORIG_LEN(4) COMP_LEN(4) EXTRA? COMP
# All integers big-endian >I / >H

Header

FieldSizeValue
MAGIC40x52 49 53 41 "RISA" (was DCM2 legacy)
VER14 = v4.1 1M/4M adaptive (was 3 = 64K/128K)
BACKEND10=huffman 1=zlib 2=lzma 3=zstd
NUM_BLOCKS4>I — 1 for <=4M single block, else ceil(len/1M)
BLOCK_SIZE4>I 4096, 16384, 65536, 131072, 1048576, 4194304 or len(data) for single
DICT_LEN4>I compressed dict length (0 if none)
DICT_ORIG_LEN4>I original dict length
DICT_COMPvarlzma.compress(dict, preset=9) if DICT_LEN>0
# Example header for v4.1 1M without dict (hex):
# 52 49 53 41 04 03 03 00 00 00 01 00 10 00 00 00 00 00 00 00 00 00 00
#  R  I  S  A  v4 zstd 1 block 1M     no dict

Blocks

FieldSizeNote
TID1Transform ID 0-16, 99, 100
EXTRA_LEN10-2, or 4 for BWT_SUBBLOCK
ORIG_LEN4>I original block length
COMP_LEN4>I compressed payload length
EXTRAvarBWT primary >H 2B, SHUFFLE stride 1B 0x02/04/08, BWT_SUBBLOCK >H sub_size + >H num + 2*num primaries
COMPvarbackend(transform(block)) e.g. zstd(level=19)

For single-block <=4M file, overhead 4+1+1+4+4+8 + per-block 10 = 32B (was 600B with 5×1M).

Streaming

from deep_compress.compressor_v3 import compress_stream, decompress_stream
with open('big.bin','rb') as fin, open('big.rissa','wb') as fout:
    compress_stream(fin, fout, block_size=131072, use_dict=False)
# for block in stream without whole-file RAM
# xor_prev_block disabled in use_mp to avoid silent wrong decode

Determinism

Sorted TRANSFORMS_V2 iteration, no hash tie-break. Same input → same .rissa.

Python API — v4.1

import rissa
compressed = rissa.compress(data, level=3) # 1:3 2:6 3:19 4:22
assert rissa.decompress(compressed) == data

# Full v4.1 with dict and two-pass
