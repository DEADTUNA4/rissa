How rissa Works

From MDL equation to 16 transforms per block — how, why, what, and with what.

What is rissa

rissa is a context-selecting compressor. For each 64K/128K block it tries 16 reversible transforms and keeps the one with lowest description length Cost(T)+Cost(Model)+Cost(Data|Model) - Rissanen MDL 1978, Kolmogorov's uncomputable shortest program made tractable.

Why not LZ77 alone

LZ77 finds exact byte copies. Structured data copies are mathematical: 1,2,3,4 delta=1, 32-bit floats share exponent bytes, sensor timestamps delta~1 with jitter. LZ sees nothing, rissa sees DELTA_ZIGZAG or SHUFFLE_4.

Does it work — Per-block MDL

File != one transform. telemetry.bin may have header (RAW), float array (FLOAT_SPLIT), counters (DELTA). rissa per-block: block 0: RAW (1+extra), block 1: SHUFFLE_8 (1+extra) - counts 1-byte tid + extra. 128K block = 0.4% header vs 3% at 16K.

for block in file.chunks(65536):
  best = min((len(backend(T(block)))+1+len(extra) for T in TRANSFORMS), key=size)
  write(tid, extra, backend.encode(best))

With what

Backends: zstd -19/-22, xz -9, zlib, huffman → rans (bits/sym vs Shannon). Dictionary: 1MB sample → 64KB header via zstandard.train_dictionary, MDL-gated.

  • IoT/Sensor: NOAA binary 500K SHUFFLE_8 ties xz 290K
  • Columnar: Yellow Taxi parquet tie at Shannon limit 1.99M
  • Logs: Loghub RAW fallback header 0.4%
  • Silesia text: per-block loses cross-block without dict
