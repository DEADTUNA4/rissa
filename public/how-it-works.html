How rissa Works

From MDL equation to 16 transforms per block - everything, how, why, what.

What: rissa is a context-selecting compressor. For each 64K/128K block it tries 16 reversible transforms and keeps the one with lowest description length Cost(T)+Cost(Model)+Cost(Data|Model) - Rissanen MDL 1978, Kolmogorov's uncomputable shortest program made tractable.

Why: LZ77 finds exact byte copies. Structured data copies are mathematical: 1,2,3,4 delta=1, 32-bit floats share exponent bytes, sensor timestamps delta~1 with jitter. LZ sees nothing, rissa sees DELTA_ZIGZAG or SHUFFLE_4.

Does it work?

Per-block MDL, not per-file

File ≠ one transform. telemetry.bin may have header (RAW), then float array (FLOAT_SPLIT), then counters (DELTA). rissa does per-block: block 0: RAW (1+extra), block 1: SHUFFLE_8 (1+extra) - counts the 1-byte transform id + extra in size. 128K block = 0.4% header vs 3% at 16K.

for block in file.chunks(65536):
  best = min( (len(backend(T(block)))+1+len(extra) for T in TRANSFORMS), key=size )
  write(tid, extra, backend.encode(best))

Verified deep_compress/test_roundtrip.py 16T + 200 fuzz + truncated → ALL PASSED. Deterministic (sorted TRANSFORMS, no hash).

All reversible, size-preserving, cost of extra (1B stride, 2B BWT primary) counted. Next: XOR-with-prev-block (needs inter-block state) flagged v4.

With what does it work?

Backends: zstd -19/-22, xz -9 (lzma), zlib, huffman → rans (deep_compress/rans.py reports bits/sym vs Shannon). Per-block transform then backend.

Dictionary: 1MB sample → 64KB header via zstandard.train_dictionary fallback 6-grams, MDL-gated (only if with+dict < without) - compressor_v3.py:12.

With what file types?

  • IoT/Sensor: NOAA binary (ts+float) 500K `SHUFFLE_8` ties `xz` 290K, beats `zstd` 353K
  • Logs: Loghub text → `RAW` (no win, correctly falls back, header 0.4%)
  • Columnar: Yellow Taxi parquet 2MB already compressed (ent 8.00) → tie at Shannon limit `~1.99M` with `SHUFFLE_8`/`BIT_TRANSPOSE` on residual
  • Silesia text: per-block alone loses cross-block (+51% dickens without dict) - needs shared dict on >1MB.
