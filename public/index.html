Context-Selecting Compression Engine for Structured, Sensor, and Columnar Data

Core Philosophy - Minimum Description Length
A computable, context-selecting approximation of MDL [Rissanen 1978]. rissa searches 16 reversible transforms per 64K/128K block and keeps the exact MDL winner.
$ pip install rissa-compress
$ rissa input.bin -o output.rissa
$ rissa -d output.rissa -o restored.bin

Why rissa

Standard zstd/xz use LZ77 + order-0 entropy. Great on text, miss math in 32-bit ints, IEEE754 floats, sensor records. rissa tries DELTA_ZIGZAG, SHUFFLE_4, FLOAT_SPLIT, BIT_TRANSPOSE per block and picks lowest Cost(T)+Cost(Model)+Cost(Data|Model).
