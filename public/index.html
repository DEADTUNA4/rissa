Context-Selecting Compression Engine for Structured, Sensor, and Columnar Data

Core Philosophy - Minimum Description Length
A computable, context-selecting approximation of MDL [Rissanen 1978]. rissa searches 16 reversible transforms per 64K/128K block and keeps the exact MDL winner.

Why rissa

The Gap

Standard tools (zstd, xz, gzip) use LZ77 + order-0 entropy. Great on text, miss math in 32-bit ints, IEEE754 floats, sensor records.

The Solution

rissa evaluates DELTA, SHUFFLE, FLOAT_SPLIT, BIT_TRANSPOSE per block and picks the lowest Cost(T)+Cost(Model)+Cost(Data|Model).

Quick Start

Python

import rissa
data = open("telemetry.bin","rb").read()
compressed = rissa.compress(data, level=3)
assert rissa.decompress(compressed) == data

CLI

rissa input.bin -o output.rissa --block 131072 --dict
rissa -d output.rissa -o restored.bin

pip install rissa-compress - python -m deep_compress.rissa
